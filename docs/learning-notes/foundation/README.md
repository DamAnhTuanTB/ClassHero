# Foundation Notes

Thư mục này lưu kiến thức nền tảng dùng chung cho nhiều tính năng.

Chỉ ghi vào đây khi chủ đề không thuộc riêng một feature end-to-end, ví dụ:

- monorepo/tooling,
- Docker local,
- Prisma/database foundation,
- shared package,
- environment/config,
- testing strategy.

Nếu một chủ đề đã được dùng trực tiếp trong feature, note feature nên link tới note foundation thay vì lặp lại toàn bộ.
