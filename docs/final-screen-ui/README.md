# Final Screen UI

Repo không còn lưu screenshot/mockup raster làm visual reference bền vững.

- Screenshot phục vụ test/review chỉ được tạo tạm trong `.codex/screenshots/`
  hoặc artifact ignored tương đương và không commit.
- UI đã được owner chốt phải ghi thành pattern ngắn trong
  `docs/ui-references/approved-patterns.md`; rule áp dụng rộng ghi trong
  `docs/11-ui-design-system.md` khi phù hợp.
- Code runtime hiện tại là nguồn kiểm chứng cuối cùng cho layout và interaction.
- HTML flow map có thể giữ khi nó là tài liệu tương tác hữu ích và không nhúng
  screenshot raster đã xóa.
