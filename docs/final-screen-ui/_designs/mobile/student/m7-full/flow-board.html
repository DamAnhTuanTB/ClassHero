M7 · Student Learning Flow

Mobile 390 × 844 · Lesson, Quiz, Flashcard, Test, Completion. Notes, Dashboard và màn Personalized riêng không thuộc lượt triển khai này.

Lesson accessQuizFlashcard TestSystem states

1. Lesson access

01Main

Lesson enrolled

Có enrollment → mở tab Bài học → xem video và tóm tắt trọng tâm, không hiện danh sách tài liệu.

02Trial

Lesson trial

Lesson cho học thử → đọc nội dung an toàn → Test vẫn bị khóa.

03Blocked

Lesson paywall

Không enrollment/trial → từ chối nội dung → quay lại khóa học hoặc mua quyền học.

2. Quiz

04Input

Quiz runner

Chọn đáp án → tùy chọn mở Gợi ý → bấm Kiểm tra đáp án → nhận màu đúng/sai và nút lời giải.

05Result

Quiz result

Submit → xem thống kê gọn → xem lại hoặc làm lại tất cả/câu sai, không hiện danh sách sai.

3. Flashcard

06Input

Flashcard study

Lật thẻ → đánh dấu đã/chưa thuộc → progress lưu theo student/card.

07Result

Flashcard summary

Kết thúc lượt ôn → xem số liệu → chỉ còn Ôn lại tất cả hoặc thẻ chưa thuộc.

4. Test và hoàn thành lesson

08Gate

Test locked

Đã đến giờ nhưng thiếu Quiz/Flashcard → tiếp tục khóa → redirect về đúng phần để ôn.

09Input

Test runner

Đủ điều kiện → bắt đầu bộ đề → trả lời trong thời gian giới hạn → submit server-side.

10Passed

Test review đạt

Điểm đạt → xem lại/làm đề mới → chọn Dùng điểm bài này để cập nhật best/completion.

10BFailed

Test review chưa đạt

Điểm dưới ngưỡng → cảnh báo bắt buộc làm lại → Dùng điểm bài này bị khóa.

11Success

Completion và Top 5

Dùng kết quả đạt → transaction cập nhật best/progress → hiển thị hoàn thành và Top 5.

5. System states

12Loading

Lesson loading

Đọc session và tải aggregate/progress → skeleton ổn định → thay bằng lesson thật.

13Error

Content error

API/network lỗi → giữ progress an toàn → cho thử lại hoặc quay về lộ trình.
