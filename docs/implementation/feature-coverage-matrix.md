Ghi chú coverage hiện tại của `M9.2`:

- Nhánh này đã loại renderer JSON cũ. Summary contract version 3 chỉ giữ
  `TEX_FIGURE` reference cùng `figureOrigin` backend-derived để JSON phân biệt
  nguồn SGK với hình dựng từ brief; JSON review admin chiếu read-only
  `sourceReferences` Phase 1 từ figure plan, còn source locator/state/audit chuẩn
  vẫn nằm ở bảng riêng.
- Giai đoạn hiện tại chỉ làm figure cho “Sinh kiến thức”. Quiz, Flashcard, Test,
  Explanation và Chat giữ text-only.
- Prompt và test invariant bắt buộc lớp 3–12. Coverage runtime phụ thuộc bộ package
  cố định trong Docker image và admin visual review, không dùng AI Vision.
- Coverage figure dùng quy tắc hai tầng: subject profile bắt buộc mức sàn và
  semantic gate chặn thiếu hình trước persist; danh sách không đóng nên figure AI
  chủ động đề xuất ngoài mức sàn vẫn được chấp nhận.
- Figure light-only; dark UI dùng surface sáng.
- Contract v2 đã bị ADR-0018 supersede. Corrective M9.2 đã hard cutover sang plan
  v3, xóa `visualIntent`, không có
  reader/dual contract/fallback. Stage 2 dùng ảnh + target + projection block,
  hoặc chỉ projection block khi không ảnh.
- Migration dữ liệu đã cancel/invalidate job và snapshot v2; runtime strict reject
  payload cũ, gate source mơ hồ, projection block không gửi
  solution/answer/conclusions và API/UI không còn field cũ. Deploy phải cập nhật
  API/web/worker đồng thời và restart worker.
- Không chạy live OpenAI matrix trong verification mặc định. Mọi paid test phải
  được owner duyệt sau khi báo số lượt và ước tính chi phí.

## Khi nào cập nhật file này

- Khi thêm, xóa, hoãn hoặc đổi phạm vi feature.
- Khi hoàn thành một task làm thay đổi status feature.
- Khi phát hiện feature thiếu DB/API/UI/worker/test task.

Không dùng file này để tự thêm scope ngoài MVP. Nếu matrix thiếu task, cập nhật docs milestone trước hoặc cùng lúc.
