## M7: Student learning flow

### M7.1: Access check, trial lesson và lesson page skeleton

Mục tiêu:

- Enforce quyền học theo enrollment/trial.

Phạm vi:

- Enrollment check.
- Trial first lesson check.
- Student lesson page/API skeleton.
- Breadcrumb/metadata thể hiện lesson đang thuộc chapter nào.

Done khi:

### M7.2: Quiz attempt và submit

Mode: UI + API

Mục tiêu:

- Student làm quiz.

Phạm vi:

- Start quiz attempt.
- Submit answers.
- Với `TRUE_FALSE`, payload answer là một boolean. Với
  `MULTI_STATEMENT_TRUE_FALSE`, payload answer ánh xạ lựa chọn Đúng/Sai theo
  từng `statementId`; review trả kết quả đúng/sai ở cấp mệnh đề. Điểm của câu
  được chia đều cho số mệnh đề; mỗi mệnh đề đúng nhận phần điểm của chính nó,
  mệnh đề sai nhận 0.
- Chấm điểm/số đúng/số sai.
- Làm lại tất cả.
- Làm lại câu sai nếu nằm trong contract.

Done khi:

- Quiz attempt lưu lịch sử.
- Kết quả trả đúng số câu đúng/sai.

### M7.4: Test start, submit và review

Mode: UI + API

Mục tiêu:

- Student làm bài kiểm tra.

Phạm vi:

- Chỉ mở test sau `exam_open_at`.
- Start test attempt.
- Submit answers.
- Với `TRUE_FALSE`, payload answer là một boolean. Với
  `MULTI_STATEMENT_TRUE_FALSE`, payload answer ánh xạ lựa chọn Đúng/Sai theo
  từng `statementId`; review trả kết quả đúng/sai ở cấp mệnh đề. Điểm hiệu lực
  của câu được chia đều cho số mệnh đề; mỗi mệnh đề đúng nhận phần điểm của
  chính nó, mệnh đề sai nhận 0.
- Score trên thang 10.
- Review toàn bộ đề và câu sai.
- Mỗi lần làm là một bộ đề khác nếu có.

Done khi:

- Test bị chặn trước giờ mở.
- Attempt lưu đầy đủ answers/score/duration.

Quy tắc đã chốt cho `M7.2`/`M7.4`: nếu câu có `N` mệnh đề và điểm hiệu lực là
`P`, mỗi mệnh đề có trọng số `P / N`. Tổng điểm câu bằng tổng trọng số của các
mệnh đề đúng; không áp dụng all-or-nothing. `isCorrect` ở cấp câu chỉ là `true`
khi mọi mệnh đề đều đúng, còn điểm vẫn giữ phần đúng đã đạt.

### M7.5: Best attempt, lesson completion và top 5

Mode: API only

Mục tiêu:

- Tính kết quả tốt nhất và hoàn thành lesson.

Phạm vi:

- Best attempt rule: điểm cao hơn, nếu bằng thì thời gian nhanh hơn.
- Lesson completed khi best score >= 7.
- Top 5 trong lesson theo score/time.
- Transaction/idempotency khi update best/progress.

Done khi:

- Best attempt đúng rule.
- Lesson chỉ completed khi đạt điều kiện.
- Top 5 trả đúng thứ tự.

### M7.7: Student dashboard UI

Mode: UI + API

Mục tiêu:

- Có dashboard học sinh để vào học nhanh và xem tiến độ chính.

Phạm vi:

- Danh sách lộ trình đang học.
- Tiến độ gần đây.
- Bài học tiếp theo/gần đây.
- Kết quả/best attempt nổi bật nếu đã có.
- Top 5/test summary nếu `M7.5` đã có.
- Notification/XP có thể dùng placeholder nếu `M10.x`/`M13.x` chưa hoàn tất.

Done khi:

- Student đăng nhập thấy dashboard có dữ liệu học tập chính.
- CTA dẫn đúng vào course/chapter/lesson đang học.
- Placeholder cho notification/XP không phá layout và được nối thật ở task sau.

### M7.8: Student personalized learning path access và progress

Mode: UI + API

Mục tiêu:

- Student học đúng lộ trình hiệu lực của enrollment và giữ lịch sử trước khi cá nhân hóa.

Phạm vi:

- Effective learning path resolver cho course detail, lesson access, previous/next và dashboard.
- Progress/continue/completion denominator theo bản được giao.
- Ánh xạ source lesson để giữ completed/best score/history và chống cộng XP trùng.
- Badge `Lộ trình cá nhân` trên student course detail.
- Bảo vệ ownership ở backend cho path/lesson riêng tư.

Done khi:

- Chỉ đúng student sở hữu enrollment truy cập được bản cá nhân.
- Lesson mới bắt đầu chưa học; lesson nguồn đã hoàn thành giữ trạng thái hợp lệ.
- Sau activation, mọi dữ liệu học tập mới ghi vào lesson/content của bản cá nhân.
- Không có flow quay lại khóa gốc.
