# M2. Auth, RBAC và backend foundation

Chi tiết phạm vi, Không làm và Done khi cho các subtask M2.x.

---

## M2: Auth, RBAC và backend foundation

### M2.1: Backend foundation module

Mode: API only

Mục tiêu:

- Chuẩn hóa nền API trước khi làm auth/domain.

Phạm vi:

- ConfigModule với env validation.
- PrismaModule nếu chưa làm ở M1.
- Global validation pipe.
- Error response format.
- Swagger/OpenAPI setup.
- Logger cơ bản.

Done khi:

- API build được.
- Swagger chạy ở dev.
- Thiếu env bắt buộc báo lỗi rõ.

### M2.2: Register, login, refresh và logout

Mode: API only

Mục tiêu:

- Hoàn thiện auth cơ bản.

Phạm vi:

- Register student.
- Register parent.
- Login bằng username/email/số điện thoại theo contract.
- Password hashing.
- JWT access token.
- Refresh token hash/revoke.
- Logout revoke refresh token.

Done khi:

- Student/parent register được.
- Login trả access/refresh token.
- Refresh token rotate/revoke đúng rule.

### M2.3: RBAC, `GET /me`, profile base và forgot/reset password

Mode: API only

Mục tiêu:

- Enforce role và hoàn thiện account API nền.

Phạm vi:

- Role decorator/guard.
- `GET /me`.
- API profile cơ bản theo contract.
- Forgot password.
- Reset password bằng `password_reset_tokens`.
- Test permission admin/student/parent tối thiểu.

Done khi:

- Admin endpoint bị chặn nếu không phải admin.
- Student/parent chỉ đọc/sửa phần được phép.
- Reset token không lưu raw token.

### M2.4: Auth UI login/register/forgot password

Mode: UI + API

Mục tiêu:

- Có giao diện auth public để user đăng ký, đăng nhập và khôi phục mật khẩu.

Phạm vi:

- Login page.
- Register student page.
- Register parent page.
- Forgot/reset password page.
- Form validation bằng React Hook Form + Zod.
- Kết nối API từ `M2.2` và `M2.3` nếu đã có; nếu làm `/task-ui` thì dùng mock handler/data.
- Lưu session/token client-side theo pattern auth được chốt ở `M2.2`/`M2.3`.

Done khi:

- Student/parent đăng ký và đăng nhập được từ UI.
- Forgot/reset password UI gọi đúng API contract.
- UI có loading/error/success state rõ trên mobile và desktop.
