# Task UI Plan Mode

Read only for `/task-ui plan ...`.

- Planning is read-only: do not edit files, create screenshots, install packages,
  stage, commit or begin implementation.
- Inspect only enough code/patterns to identify ownership, reuse, states,
  responsive behavior, mock shape, risks and credible checks.
- Output an approval-gated plan with task ID/Mode, screen goal, inspected sources,
  likely route/component/hook/schema/mock files, layout/states/responsive approach,
  explicit backend exclusions, checks and assumptions.
- Record inspected paths and current Git condition so `/do` can delta-revalidate
  instead of repeating discovery. Stop for owner approval.
